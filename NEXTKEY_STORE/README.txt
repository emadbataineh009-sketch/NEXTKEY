NEXTKEY - متجر مشترك بين جميع الزوار

هذا الإصدار يستخدم Backend وقاعدة بيانات على السيرفر.
أي منتج يضيفه المسؤول يتم حفظه في products.json على السيرفر، لذلك يظهر لجميع زوار نفس الموقع.

التشغيل:
1) ثبّت Node.js 18 أو أحدث.
2) افتح Terminal داخل مجلد NEXTKEY_STORE.
3) شغّل: npm start
4) افتح: http://localhost:3000

كلمة مرور الإدارة الافتراضية: 3292EM
النسخة المنشورة لا تحتوي كلمة المرور كنص داخل الواجهة؛ الخادم يقارن SHA-256.

للسيرفر السحابي:
- ارفع كامل المجلد.
- شغّل npm start.
- يفضّل تعيين متغير البيئة ADMIN_PASSWORD_HASH إلى SHA-256 لكلمة مرور جديدة.
- يجب أن يكون تخزين الملفات دائماً (Persistent Storage) حتى لا تضيع products.json عند إعادة تشغيل السيرفر.
